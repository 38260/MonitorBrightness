# MonitorBrightness · 显示器亮度悬浮条 + 托盘图标

一个纯 Python 标准库（+ Pillow）写的 Windows 小工具：通过 **DDC/CI** 协议（VCP 代码 `0x10`）直接调节外接显示器的硬件亮度，
不碰 Windows 自己的亮度设置。界面上只有一根可以钉在屏幕角落的悬浮条和一个会显示当前亮度数字的托盘图标。

> 仅支持 Windows。调节的是显示器 OSD 里的亮度，跟显卡驱动/笔记本内屏那套亮度不是同一个通道。

## 它能做什么

| 入口 | 操作 | 效果 |
| --- | --- | --- |
| 悬浮条 | 拖滑块 / 在条子上滚滚轮 | 连续调亮度 |
| 悬浮条 | `−` `+` | 按 5 步进 |
| 悬浮条 | 双击中间的数字 | 恢复默认亮度 |
| 悬浮条 | 双击背景 | 解锁/锁定位置（锁定时蓝框消失、拖不动） |
| 悬浮条 | `×` | 隐藏到托盘（程序不退出） |
| 悬浮条 | 右键 | 菜单：恢复默认亮度 / 设置默认亮度… / 隐藏到托盘 / 退出 |
| 托盘图标 | 滚轮悬停在图标上 | 调亮度（步进 5） |
| 托盘图标 | 左键 | 显示 / 隐藏悬浮条 |
| 托盘图标 | 右键 | 显示/隐藏、恢复默认、设置默认亮度、开机自启、退出 |
| 全局 | `Ctrl + Alt + ↑` / `↓` | 任意窗口下都能调亮 / 调暗 |

其他行为：

- **托盘图标上直接印着当前亮度数字**，亮度变了图标就重绘。
- **10 秒无操作自动隐藏**悬浮条（鼠标停在条子上时不会隐藏）。
- **开机自启**：托盘菜单里勾上即写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，
  并在开机时把亮度设成 `brightness.txt` 里的默认值。
- **唯一实例**：重复启动不会再开一个托盘图标，只会把已在运行那个实例的悬浮条叫出来
  （命名互斥体 `Local\SancBrightnessWidget.single` + 唤醒事件，句柄随进程释放）。

## 快速开始

```bat
:: 1. 装依赖（Pillow 只用来画托盘图标）
pip install pillow

:: 2. 双击目录里的 打开亮度悬浮条.cmd —— 无控制台窗口
::    或者直接跑 python brightness_widget.py
```

想要不带黑框的桌面快捷方式，就自己新建一个 `.lnk`，目标填 `pythonw.exe`、参数填 `brightness_widget.py` 的绝对路径。

`打开亮度悬浮条.cmd` 和 `apply-brightness.cmd` 里写死了 `D:\env\Anaconda\python.exe` / `pythonw.exe`，
文件里已有回退逻辑（找不到就用 `PATH` 里的 `python` / `pythonw`）。如果你的 Python 装在别处，改这两行更省事。

## 默认亮度

默认亮度存在同目录的 `brightness.txt`，就是一个 0–100 的数：

```
# 默认亮度（0-100），改完保存即可；也可以在托盘/悬浮条右键菜单里设置。
# 每次启动本程序（含开机自启）都会把显示器设成这个值。
40
```

- 手动改：右键菜单「设置默认亮度…」输入数字，程序会把值写回这个文件。
- 直接编辑文件也行，下次启动生效。
- 文件缺失或没有有效数字时，代码回退到 45。
- 仓库里没有带这个文件（里面是各人自己的偏好值）。可以自己新建一个只写数字，
  或者用一次「设置默认亮度…」让程序生成。
- 这个值同时是「恢复默认亮度」和开机亮度的目标，改完重启自启项也跟着变。

## 命令行用法

不想要界面时（比如挂到计划任务、快捷键、或者写到别处的启动脚本里）：

```bat
python set_brightness.py            :: 列出所有显示器及当前亮度，只看不改
python set_brightness.py 40         :: 所有支持 DDC 的显示器设为 40
python set_brightness.py 40 0       :: 只改第 0 台
python set_brightness.py apply      :: 读取 brightness.txt 并应用
```

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `brightness_widget.py` | 主程序：tkinter 悬浮条 + 全局热键线程 + 事件轮询 |
| `tray.py` | 托盘图标，纯 ctypes 调 `Shell_NotifyIcon`；滚轮用 `WH_MOUSE_LL` 低级鼠标钩子判定悬停 |
| `set_brightness.py` | DDC/CI 封装（`EnumDisplayMonitors` → `dxva2` 读写 VCP `0x10`），也是命令行入口 |
| `brightness.txt` | 默认亮度配置（0–100） |
| `widget_state.json` | 运行状态：悬浮条坐标、是否锁定、是否可见 —— 是程序自己写的，不用手动改 |
| `打开亮度悬浮条.cmd` | 一键启动（无黑框窗口） |
| `apply-brightness.cmd` | 一键把亮度设成 `brightness.txt` 的值 |

界面尺寸按 384×54 的设计稿绘制，运行时乘 DPI 缩放系数，所以 2K/4K 高分屏下发虚的问题已经处理掉了
（启动时先 `SetProcessDpiAwareness`）。

## 已知限制

- **只有走 DDC/CI 的显示器能调**。笔记本内屏、以及部分虚拟机/采集卡显示器读不到 VCP `0x10`，
  程序会跳过它们（`set_brightness.py` 裸跑会显示"不支持调节"）。
- 有些显示器要在自己的 OSD 菜单里手动打开 `DDC/CI` 开关，否则写进去没反应。
- 个别型号把亮度最低值不是 0，写到 0 可能黑屏，需要按显示器上限调整。
- 快捷键 `Ctrl+Alt+↑/↓` 是全局注册，如果已被系统或其他软件占用，会在悬浮条上提示"全局热键被占用"。
- 托盘图标的滚轮依赖低级鼠标钩子。这是系统级的回调，程序退出时会自动卸载。
- 进程被强杀（任务管理器、断电）时来不及调 `NIM_DELETE`，那个图标会作为"死图标"赖在通知区，
  直到鼠标划过一次才被系统清掉。这是 explorer 的缓存行为，不是多开出来的进程。
- 资源管理器重启后托盘图标会消失（程序没订阅 `TaskbarCreated` 消息），重新打开一次即可。
